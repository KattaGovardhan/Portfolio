# Govardhan Katta — Portfolio

The source repository for my personal developer portfolio, built to present my work, technical focus, and experience through a fast, responsive web experience.

## Overview

The portfolio is designed around a simple goal: make it easy for recruiters, clients, and other developers to understand what I build and how I approach software engineering.

## Features

- Responsive portfolio experience across desktop and mobile
- Project showcase driven by reusable data
- Interactive UI and motion
- Contact form for direct enquiries
- Resume download
- Reusable component-based structure
- Production deployment with automated delivery

## Tech Stack

| Area | Technology |
| --- | --- |
| Framework | Next.js |
| UI | React, Tailwind CSS |
| Motion | Framer Motion |
| Icons | React Icons |
| Contact | Web3Forms |
| Deployment | Vercel |

## Project Structure

```text
app/          Application routes and layout
components/   Reusable UI components
constants/    Portfolio content and configuration
public/       Static assets
```

## Local Development

### Prerequisites

- Node.js 18+
- npm, pnpm, or yarn

### Setup

```bash
git clone https://github.com/KattaGovardhan/portfolio.git
cd portfolio
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production

The project is intended for deployment on Vercel, with production builds generated from the main branch.
